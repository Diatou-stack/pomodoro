# Nuage Pomodoro

Application Pomodoro cozy / dreamcore pour l’apprentissage et la concentration.

## Fonctionnalités

- Chronomètre Pomodoro configurable (étude / pause)
- Citations motivantes (rotation toutes les 10 s)
- Sons de nature : pluie, vagues, vent, forêt

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Motion · Lucide

## Lancer

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).
